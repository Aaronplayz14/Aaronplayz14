# 🎮 Projects:

### 🃏 Rogue Party

A multiplayer roguelike deckbuilder built with **Unity, C#, Python, and JSON**. Players join through their phones while a central Unity client manages the shared game experience.

- Multiplayer room management and player synchronization
- Client-server communication and real-time game-state updates
- Character selection, cards, abilities, and progression systems

### 👻 GhostBoard

A local-first job application organizer combining an **Electron desktop application** with a **Chromium MV3 browser extension**.

- Tracks job applications from discovery through follow-up
- Uses TypeScript, React, Python, Electron, SQLite, and browser extension APIs
- Includes deterministic job matching and resume keyword analysis
- Uses AI to tailor LaTeX resumes while preserving the original master resume

### 🐦 Aviary

A puzzle-adventure game built with **Unity and C#**, where players use different bird abilities to solve environmental puzzles and escape an abandoned zoo.

- Gameplay systems and interactive environments
- Rotating pipe puzzles and environmental barriers
- Pathfinding and movement systems
- Collaborative five-person game development team

### 🦾 Synapse Sprinter

A 72-hour hackathon project using **Arduino and Python** to turn real-time muscle movement data into game controls.

- Arduino hardware integration
- Real-time input processing
- Muscle movement-based game controls
- Two-player Crossy Road-style gameplay
